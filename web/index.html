v0.3 · Node 22+ · Token 不离开本机

1. Cloudflare API Token

域名必须已经接入 Cloudflare。这里只要用户 API 令牌（My Profile → API Tokens）。不要用账户令牌（cfat_ 开头），也不要用 Global API Key。Wrangler 需要 Node.js 22+，低于 22 时会在部署流程里自动下载便携版。

最快：不要在 Create Custom Token 里一项项勾。已登录 Cloudflare 时，复制下面脚本，到 dash.cloudflare.com 按 F12 → Console → 粘贴回车，会按本项目所需权限直接创建 Token。
或用官方预填链接

脚本成功会把 Token 复制到剪贴板，再粘到本页验证。若被 Cloudflare 拦截，会自动跳转预填页；下拉框看起来是空的也直接点 Continue to summary → Create Token。

Cloudflare 没有「全选权限」。备选模板：Edit Cloudflare Workers，再手补 Email Routing / DNS / SSL。文档 doc.skymail.ink

2. 选择域名

邮箱域名用于 MX / Catch-all。站点域名给 Web 邮箱界面，默认 mail.你的域名，避免占掉官网首页。

3. 正在部署

首次会检查 Node 22+（不够就自动下载）、安装 pnpm、克隆官方仓库并构建 Vue 前端，通常需要几分钟。日志在下方，Token 只用于本机调用 Cloudflare API / wrangler。

清空已部署

输入站点域名（如 mail.example.com）、邮箱域名或 Worker 名称。先预览再确认，默认删除 Worker / D1 / KV / 自定义域，并关闭指向该 Worker 的 Catch-all。不会删除 Cloudflare 账号或 Zone。

4. 完成

部署结束。用管理员邮箱在站点里注册第一个账号。
